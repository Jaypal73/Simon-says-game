# 🎮 Simon Says Game

A fun and interactive memory-based game built using **HTML, CSS, and JavaScript**. Test your memory by remembering and repeating the sequence of colors displayed by the game.


## 📸 About the Game

Simon Says is a classic memory game where players need to remember the sequence of flashing colors and repeat it correctly.

With every successful round, the sequence becomes longer and the difficulty increases.

## ✨ Features

- Interactive and colorful game interface.
- Random color sequence generation.
- Increasing difficulty with every level.
- Keyboard interaction to start the game.
- Score and level tracking.
- Game Over detection when an incorrect sequence is entered.
- Responsive design for different screen sizes.

## 🛠️ Technologies Used

- **HTML5** – Structure of the game.
- **CSS3** – Styling, animations, and visual effects.
- **JavaScript** – Game logic, event handling, and sequence generation.

## 🎯 How to Play

1. Press any key to start the game.
2. Watch carefully as the game flashes a color.
3. Click the same color button.
4. Remember the previous sequence as new colors are added.
5. Repeat the complete sequence correctly to reach the next level.
6. If you select the wrong color, the game ends.
